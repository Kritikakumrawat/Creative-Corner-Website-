# Creative Corner Website

A clean, responsive and user-friendly website developed using HTML, CSS and JavaScript. The project focuses on creating an engaging browsing experience with structured content, interactive navigation and a responsive layout.

## Overview

Creative Corner is a front-end web development project designed to demonstrate the practical implementation of HTML, CSS and JavaScript.

The website consists of multiple sections, including Home, About, Explore and Contact, allowing users to navigate through the content easily. JavaScript adds interactive functionality such as mobile navigation and basic contact form validation.

The main focus of this project is to create a simple, visually appealing and easy-to-use website while maintaining a well-organized code structure and responsive design.

## Features

- **Responsive Design:** Adapts the website layout to desktop, tablet and mobile screens.
- **Navigation Bar:** Provides easy access to different sections of the website.
- **Home Section:** Introduces the website with a welcome message and an Explore More option.
- **About Section:** Provides information about the website.
- **Explore Section:** Displays content using organized and visually structured cards.
- **Contact Form:** Allows users to enter their name, email address and message.
- **Mobile Navigation:** Includes a toggle menu for smaller screen sizes.
- **Smooth Scrolling:** Provides smooth navigation between different sections.
- **Form Validation:** Checks required fields before displaying a confirmation message.

## Technologies Used

| Technology | Purpose |

## Getting Started

Follow these steps to run the project on your local system.

### Prerequisites

- A modern web browser such as Google Chrome or Microsoft Edge.
- Visual Studio Code or any other code editor.
- Git (for cloning the repository).

### Installation and Setup

**1. Clone the repository**

```bash
git clone https://github.com/Kritikakumrawat/Creative-Corner-Website-.git
```

**2. Navigate to the project directory**

```bash
cd Creative-Corner-Website-
```

**3. Open the project in Visual Studio Code**

```bash
code .
```

**4. Run the website**

Open `index.html` using the Live Server extension in Visual Studio Code.

Alternatively, you can open the `index.html` file directly in your web browser.

## How the Website Works

1. The browser loads the webpage using the HTML structure.
2. CSS styles the content and adjusts the layout according to the screen size.
3. JavaScript runs after the HTML document has loaded.
4. Users can navigate between Home, About, Explore and Contact sections.
5. On smaller screens, the navigation menu can be opened and closed using the menu button.
6. The contact form checks the entered details and displays a confirmation message when valid information is submitted.

## Contact Form Functionality

The contact form includes basic front-end validation using JavaScript.

- Checks whether the required fields are filled.
- Prevents the default form submission.
- Displays a confirmation message after valid input.
- Resets the form after displaying the message.

**Note:** The contact form currently works on the front end only. It does not send emails or store submitted information in a database.

## Responsive Design

The website uses CSS media queries to adjust its layout for different screen sizes.

- **Desktop:** Full navigation menu and multi-column card layout.
- **Tablet:** Adjusted spacing and content layout.
- **Mobile:** Toggle-based navigation and single-column card layout.
